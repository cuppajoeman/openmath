Linear Combination
A linear combination of the vectors \( \left\{ v _ 1, \ldots, v _ m \right\} \) of vectors in a vector space \( V \) is: \[ a _ 1 v _ 1 + \ldots + a_m v_m \] where \( a_1, \ldots, a_m \in \mathbb{F} \)
Span
The set of all linear combinations of the vectors \( \left\{ v _ 1, \ldots, v _ m \right\} \subseteq V\) (where \( V \) is a vector space) called the span of \( \left\{ v_1, \ldots, v_m \right\} \) and we define the notation: \[ \operatorname{ span } \left( \left\{ v_1, ..., v_m \right\} \right) := \left\{ a_1 v_1 + \ldots + a_m v_m: a_1, ..., a_m \in \mathbb { F } \right\} \] we define \( \operatorname{ span } \left( \emptyset \right) := \left\{ 0 \right\} \)
Linearly Independent
Let \(V\) be a vector space over a field \(F\). A set of vectors \(\left\{v_1,\ldots,v_m\right\}\subseteq V\) is linearly independent if, for scalars \(a_1,\ldots,a_m\in F\), the only solution to \[ \sum _ { i = 1 } ^ m a_i v_i = 0 \] is \(a_1=\cdots=a_m=0\). We define \(\emptyset\) to be linearly independent.
A Set Containing Zero Is Not Linearly Independent
Let \(V\) be a vector space over a field \(F\), and let \(S=\{v_1,\ldots,v_m\}\subseteq V\). If \(0\in S\), then \(S\) is not linearly independent.
Choose \(j\) with \(v_j=0\). Set \(a_j=1\) and \(a_i=0\) for every \(i\neq j\). Then \[ \sum_{i=1}^m a_i v_i =1\cdot v_j+\sum_{i\neq j}0\cdot v_i =0, \] even though \(a_j\neq 0\). This contradicts the definition of linear independence.
General Linear Independence
A set \( S \subseteq V \) is said to be generally linearly independent if for every every finite subset \( F \subseteq S \), \( F \) is linearly indepenent
Spanning Set
Suppose that \( V \) is a vector space, then we say that \( S \) is a spanning set of \( V \) if \( \operatorname{ span } \left( S \right) = V \)
Linearly Independent iff Unique Representation
\( \left\{ v_1, \ldots, v_m \right\} \) is linearly independent iff each vector in the set \( \left\{ v_1, \ldots, v_m \right\} \) has only one representation as a linear combination of \( \left\{ v_1, \ldots, v_m \right\} \)
Linearly Dependent
\( \left\{ v_1, \ldots, v_m \right\} \subseteq V \) is said to be linearly dependent if it is not linearly independent
Linearly Depedent iff Zero has a Non-Trivial Representation
\( \left\{ v_1, \ldots, v_m \right\} \subseteq V \) is linearly dependent iff there exists \( a_1, \ldots, a_m \in \mathbb { F } \) and \( i \in \left[ 1,m \right] \) where \( a_i \neq 0 \) such that \( \sum _ { i = 1 } ^ m a_i v_i = 0 \)
